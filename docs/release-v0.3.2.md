# HayakuReader v0.3.2

## 打印与预览

- 新增打印窗口：打印机、纸张、方向、份数、页码范围、颜色、页边距及单双面设置。
- 可选择打印高亮与笔记；笔记栏通过浅色连线指向正文，支持长笔记续页、首页位置选择及双面左右交替。
- PDF 保留原页面比例；Word 和流式文档按正文栏宽度重排。
- Markdown、EPUB 等使用原生富文本渲染，保留标题、强调、列表、表格、代码高亮、图片、公式及振假名。
- 首次仅生成前 5 页预览，翻页时按需缓存当前页后的 5 页；实际打印补齐所选范围内未预览的页面。
- 修复打印窗口高度不足、长打印机名称撑宽面板，以及长篇 EPUB 字体图集重建导致的预览乱码。
- 默认页边距调整为 25 mm；流式文档采用独立的 10.5 pt 正文和 1.6 行距。

## 阅读与界面

- 恢复上次窗口位置、大小和最大化状态。
- 界面缩放支持 50%–200%，改用下拉菜单，避免拖动时缩放失控。
- 精简设置面板，统一左侧标签和数值框宽度，缩小设置及搜索标题。
- 标签标题最多显示 50 个字符，超长时省略中间文字。
- 修复浮层遮挡时背景标签仍然高亮的问题。
- 正文右键支持全选、打印、在点击位置插入书签，以及编辑高亮和笔记。
- 移除顶栏笔记、书签按钮，将代码模式切换移至左下状态栏，并明确标注阅读进度。

## 下载

下载唯一附件 `HayakuReader.exe`。Windows x64 单文件程序，无需 WebView2；支持按用户安装与文件关联。

复杂 Word 排版可能存在显示差异；受 DRM 保护或 HUFF/CDIC 压缩的 Kindle 文件暂不支持。
