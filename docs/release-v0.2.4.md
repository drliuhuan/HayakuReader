# HayakuReader v0.2.4

- **安装快捷方式**：首次安装到个人目录后，自动在「开始菜单」和「桌面」创建 `HayakuReader` 快捷方式。
- **启动与起始页**：通过关联文件打开时，文件加载完成即刻关闭启动画面；起始页新增仓库直达链接和最近阅读快捷入口，并支持单条删除与清空阅读历史。
- **深色模式智能反色**：新增仅在深色模式下显示的「页面智能反色」开关（默认开启），基于 OKLab / WCAG 4.5:1 对中性色平滑反演、鲜亮色原样保留、暗彩色锁定色相提亮，同时保留 PDF / Word / 流式文档中的插入式图片，并对扫描式/图片式 PDF 整页执行智能反色。
- **Markdown / HTML 代码模式**：打开 Markdown 或 HTML 文件时支持在「渲染模式」与「代码模式」之间切换，代码模式提供 CSS 行号与适配浅色/深色主题的编辑器语法高亮配色。
- **阅读交互与快捷键**：新增 `Ctrl+O/F/B/W/Tab`、`Ctrl+滚轮` 缩放、`F11` 专注模式与 `Esc` 分层退出；设置与搜索面板改为悬浮布局，支持搜索上下条跳转与计数、滑块数值显示及一键恢复默认。
- **批注与目录体验**：选区浮动栏支持黄/绿/蓝/粉四色一键高亮且不再强制弹出侧栏，点击正文高亮可直接编辑，支持一键导出批注为 `.md` 文件；目录侧栏实时高亮当前所在章节，并完善 EPUB / Kindle 多级目录与页内锚点跳转。
- **格式与稳定性**：为 PDF 增加 HTTP `Range` / `HEAD` 分块加载以解除 64 MiB 限制、缓存 EPUB ZIP 句柄并并发加载章节、修复重启/后台保存 `keepalive` 体积上限与标签会话泄漏，并自动清理更新残留文件。
