# HayakuReader v0.2.5

- **PDF / Word 页面内存回收**：新增基于 LRU 的离屏页面释放机制（PDF 最多常驻 12 页，Word 最多常驻 10 页），并调优单页渲染像素预算，大幅降低长文档连续翻页时的峰值内存与显存占用。
- **滚动与批注热路径优化**：常规滚动进度更新跳过耗时的光标锚点与全章文本计算，仅在保存进度、书签和笔记时采集；高亮刷新通过 `requestAnimationFrame` 合并并在无批注时短路跳过。
- **零分配智能反色与零拷贝资源响应**：暗色智能反色采用内联查表与纯黑/纯白直通路径消除每像素数组分配；后端内嵌前端及 `PDF.js` 静态资源改为零拷贝响应并附带缓存头，同时加大文件哈希读取缓冲区。
- **发布构建体积与性能优化**：启用 Thin LTO、单 codegen unit 与符号剥离编译配置，进一步减小单文件可执行程序体积并提升运行性能。
