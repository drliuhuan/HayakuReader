# HayakuReader v0.2.6

- **消除小字号彩色毛边并恢复原始清晰度**：优化 OKLab 中性灰平滑过渡区间（`0.065..0.13`）、移除低彩度强行放大并升级至 `65³` LUT，消除小字/低缩放 PDF 开启智能反色时的边缘彩色毛边；同时恢复 PDF / Word 1,200 万像素预算（保留 LRU 内存回收），并对小缩放 PDF 启用 2× 超采样渲染。
- **修复部分电脑无法打开 PDF 的兼容性问题**：将内嵌的 `PDF.js` 切换为自带完整 polyfill 的 legacy 构建，兼容旧版 Windows WebView2 Runtime；为路径规范化增加 `absolute()` 回退，并为旧版 WebView2 增加 `100vh` 布局高度兜底。
- **错误提示常驻**：打开或渲染失败时的错误提示不再自动消失，点击提示条即可关闭，便于排查问题。
