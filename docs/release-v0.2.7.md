# HayakuReader v0.2.7

- **无边框自定义标题栏**：隐藏原生 Windows 标题栏（保留系统阴影、圆角与最大化不遮挡任务栏），界面顶部工具栏与侧栏标题区域支持拖动移动窗口和双击最大化/还原，右上角提供最小化、最大化/还原、关闭按钮，并保留窗口边缘缩放。
- **状态栏智能反色开关与首次气泡提示**：将「已启用智能反色 / 已关闭智能反色」开关从阅读设置移至底部状态栏显著位置，避免误判 PDF 等文档色彩；首次在深色模式触发智能反色时弹出引导气泡，点击「我知道了」后不再重复提示。
- **控件禁止选中与正文专属全选**：禁止按钮、工具栏、侧栏等界面控件被误选；`Ctrl+A` 仅全选文档正文，遇到未完全加载文本层的大 PDF / Word 时先弹出「正在加载剩余页面…」进度条，加载完毕后自动全选正文。
